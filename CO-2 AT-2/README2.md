# LAN & Multiple Access

## Objective
To create a simple LAN using Cisco Packet Tracer and compare the working of a switch and a hub.

## Tools Used
- Cisco Packet Tracer

## Observation
A switch sends data only to the destination device, reducing collisions and improving network performance. A hub broadcasts data to all connected devices, which increases unnecessary traffic and collisions. Therefore, switches are preferred over hubs in modern LANs.
